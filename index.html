SYSTEM REFERENCE // COMMANDS & FEATURES

Welcome to Octinity v5.0. This environment provides modular subcore simulation and terminal access.

  • /help : Lists all available command protocols in the terminal log.
  • /talk [message] : Sends a cognitive query directly through the active submodule and triggers speech synthesis output.
  • /clear : Purges current terminal scroll buffer.
  • /status : Displays current node allocation, latency, and memory footprint metrics.
  • Module Lock : Toggle button to route all terminal input directly into the selected submodule pipeline.
